Capacitor & Mobile Plugin Bridge

Investigation of native features, offline runtime support, and bridge configurations.

High Isolation Native Capacitor Plugin Isolation (Offline Block)
capacitor.config.json ▼
How it Works

The mobile app utilizes Capacitor to load the remote web application URL directly inside a native WebView container:

"server": {
  "url": "https://app.roughcut.com.au",
  "cleartext": true
}
Why it is an Issue (Will it Work?)

1. Offline Disconnect: If the user loses network connectivity (very common when grilling in backyards), the app will display a blank connection error screen. It fails to work offline.

2. Plugin Inoperability: Because the app is pulling the page from the remote server, standard native plugins (e.g. Preferences storage, Local Notifications) will fail or be undefined because the browser WebView does not load the native capacitor.js bridge scripts from the local bundle.

Action Plan: Migrate to Static Exports
  1. Change Next.js target: Add output: 'export' in next.config.ts.
  2. Remove the server.url setting from capacitor.config.json and set "webDir": "out".
  3. Bundle the build locally: Run npm run build followed by npx cap sync android to package code directly into the native APK.
Low Info Lack of Native Device Integrations
package.json ▼

The codebase currently contains no native plugin dependencies (such as `@capacitor/haptics`, `@capacitor/network`, or `@capacitor/local-notifications`). The app runs purely as a basic webview, missing out on haptic feedback when scrolling calculators or pushing background notifications when cooking timers expire.

Cryptography & JWT Timing Verification

Auditing side-channel security and session signing methods.

High Risk HMAC Signature Mismatch Timing Attacks
lib/auth.ts ▼
How it Works

Standard comparison operators (=== and !==) compare strings byte-by-byte and return immediately when a mismatch is found. This behavior leaks information about the correct signature to attackers tracking microsecond differences in server responses.

// Vulnerable Code:
if (signature !== expectedSignature) return null;
Remediation Code (Patched & Verified)

A timing-safe comparison helper was introduced to verify signature strings. Both strings are evaluated completely to ensure constant-time verification regardless of similarity:

function timingSafeCompare(a: string, b: string): boolean {
  const bufA = Buffer.from(a, 'utf8');
  const bufB = Buffer.from(b, 'utf8');
  if (bufA.length !== bufB.length) {
    crypto.timingSafeEqual(bufA, bufA); // Uniform time consumer
    return false;
  }
  return crypto.timingSafeEqual(bufA, bufB);
}

Database & SQL Dialect Compatibility

Auditing multi-dialect database wrapper layers and constraint compliance.

High Risk Postgres Unique Constraint Verification Bypass
app/api/subscribe/route.ts ▼
How it Works

When migrating to Supabase Postgres, duplicate subscription unique key violations raise error code 23505. Checking for MySQL's ER_DUP_ENTRY caused duplicate calls to crash the route handler with a 500 status code.

// Vulnerable Code:
const mysqlErr = err as { code?: string };
if (mysqlErr.code === 'ER_DUP_ENTRY') { ... }
Remediation Code (Patched & Verified)

Modified the conditional mapping to match both database drivers:

const dbErr = err as { code?: string };
if (dbErr.code === 'ER_DUP_ENTRY' || dbErr.code === '23505') {
  return NextResponse.json({ error: 'already_subscribed' }, { status: 409 });
}
Medium Blocking Synchronous File Threading
lib/db.ts ▼

The Local JSON Database proxy implements blocking synchronous calls (fs.writeFileSync) on every database save. This halts Node.js thread processing during incoming local API runs. If deployed as-is, concurrent users would experience heavy latency spikes.

Caching & Performance Audit

Auditing server side renders, frame bundles, and asset pipelines.

Medium Vercel Edge Cache Page Locking
vercel.json / next.config.ts ▼

By default, Next.js generates static routes at build time. When linked to custom Vercel domains, Vercel caches index pages at the CDN edge for hours, returning X-Vercel-Cache: HIT header statuses even after code commits have been pushed.

Remediation Steps

Verify that your vercel.json or Next.js route settings have dynamic validation enabled (e.g. revalidate = 60 or using export const revalidate = 0 on dynamic paths) to force edge nodes to purge static pages regularly.

Real Pitmaster UX Expectations

Real backyard cooks struggle with environment variables. Math calculations alone are not enough:

  • Ambient Temperature & Wind: Wind and cold ambient air temperatures consume fuel and slow cooks by 15-30% on offset smokers.

  • The resting phase: resting is critical. Dynamic rest guides based on internal meat temperature decay improve final meat texture significantly.
Competitive Strategy

How to differentiate from standard calculators (AmazingRibs, MEATER app):

  • Privacy-First: Zero forced registrations or device connections.
  • Multi-Channel Tracking: Provide web notifications or haptic alarms on mobile without pairing bluetooth devices.
