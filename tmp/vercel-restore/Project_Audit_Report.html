Top Findings & Vulnerabilities

Critical Serverless Local Filesystem Writing Violation app/api/gallery/upload/route.ts
▼

The file upload API route originally saved image files directly to the local server filesystem under public/uploads/gallery/.

const UPLOAD_DIR = path.join(process.cwd(), 'public', 'uploads', 'gallery');
await writeFile(path.join(UPLOAD_DIR, `${postId}-before.${ext(before)}`), Buffer.from(await before.arrayBuffer()));
Remediation Status: FIXED

Rewrote the upload flow to use Supabase Storage buckets via secure REST API calls if SUPABASE_URL is defined, with a robust fallback to local disk writing for developers working in local development environments. This completely avoids read-only filesystem errors on Vercel.

High Non-Constant-Time Signature Validation lib/auth.ts
▼

The custom JWT token verification functions utilized a standard inequality comparison operator (!==) to validate HMAC signatures, introducing timing side-channels.

if (signature !== expectedSignature) return null;
Remediation Status: FIXED

Replaced the comparison checks with a custom constant-time string comparison function wrapper (timingSafeCompare) that utilizes Node's built-in crypto.timingSafeEqual API safely, mitigating information leakage side-channels.

High MySQL Error Code Assumption on PostgreSQL DB app/api/subscribe/route.ts
▼

The database subscriber duplicate handling logic caught constraint violations using only the MySQL error code string, causing crashes when running under PostgreSQL.

const mysqlErr = err as { code?: string };
if (mysqlErr.code === 'ER_DUP_ENTRY') { ... }
Remediation Status: FIXED

Updated the exception filter mapping to look for both the MySQL ER_DUP_ENTRY code and the PostgreSQL unique key constraint violation code 23505. Duplicate subscriptions are now caught correctly on Supabase.

Medium Blocking Synchronous Disk I/O inside DB Proxy lib/db.ts
▼

The local DB proxy proxying calls to `local_db.json` reads and writes status dynamically during requests using blocking synchronous I/O operations.

private read(): LocalDB {
  return JSON.parse(fs.readFileSync(this.dbPath, 'utf8'));
}
Performance Recommendation

Asynchronous operations (fs.promises) should be adopted to prevent blocking Next.js single-threaded request queues in local developer environments.

Medium Hardcoded Base URL in Gallery upload app/api/gallery/upload/route.ts
▼

The upload API route contains a hardcoded reference to the custom production host domain when generating output URLs.

const BASE_URL = 'https://app.roughcut.com.au/uploads/gallery';
Recommendation

BASE_URL should be derived dynamically from req.headers.get('host') or read from an environment variable to support seamless staging, review, and test environments.

Medium Fragile Substring Database Query Parser lib/db.ts
▼

The database fallback mock proxy emulates a SQL runner by performing simple substring checking on SQL strings.

if (queryLower.includes('select name, slug, recommended_for from gear')) { ... }
Architectural Impact

Any query format update in routes will cause local mock database queries to fail silently. Emulating SQL with SQLite is recommended over manual query text parser matching.

Praise Strong Parameter Validation with Zod app/api/subscribe/route.ts

Medium Massive SQL String Matching Block lib/db.ts
▼

The LocalDBProxy implements SQL parsing by searching SQL text queries for key substrings (e.g. select count from cook_tally) and running bespoke JSON mutations.

This emulation layer makes the code fragile to change. If any developer modifies a database query string slightly inside an API route, the mock DB string matching will fail silently, causing local development errors. Real local SQLite databases should be preferred for emulation.

Security & Data Handling

Evaluation of cryptographic safety, input sanitization, and OWASP patterns.

Praise Secure Scrypt Password Hashing lib/auth.ts
▼

Authentication utilizes the Node standard crypto.scryptSync with unique 16-byte random salts. This provides solid protection against dictionary and rainbow table cracking attempts.

Low Wildcard Content-Security Policy (CSP) headers vercel.json
▼

The Content-Security Policy header allows wildcard images from any source.

img-src 'self' data: blob: https:;

Allowing https: wildcards for images opens a slight risk for XSS exfiltration of session data. Limit the domain list to your exact bucket hosts and uploads path.

Performance & Optimization

Asset compression, rendering bottlenecks, caching, and server load.

Medium Static Page Edge Cache Locking vercel.json / next.config.ts
▼

Next.js prerenders static pages at build time. When custom domains map to Vercel, the edge cache serves stale results with a long age value (e.g. over 7 hours) unless explicit revalidation is defined.

Low Heavy Client-Side Framer Motion Bundle package.json
▼

The project imports the full framer-motion library inside client bundles, raising the initial JavaScript payload size for mobile users. Consider utilizing m and lazy-loading animations via Motion's LazyMotion provider.

The Verdict

High-level code summary and recommendations.

PROS / SUCCESS What the codebase does exceptionally well
  • Clean Layouts & Styling: The styling matches the target "Ash and Ember" print aesthetic perfectly. Visual elements are clean, responsive, and completely devoid of cookie-cutter designs.
  • Zero Dependencies for Database Dialect Translation: The transparent MySQL-to-Postgres compatibility wrapper in lib/db.ts is highly innovative, translating placeholders and returning IDs without bloated ORM libraries.
  • Android Compilation: The Gradle integration handles native Android building beautifully.
CONS / CRITICAL RISK Fatal flaws and maintenance debts
  • Read-Only Serverless assumption (Vercel): Trying to write local files in serverless handlers will fail in production. Cloud storage must be used.
  • Postgres unique constraint checks: MySQL error code assumptions will bypass unique checks on Supabase and raise database errors on duplicates.
  • Synchronous disk writes in local fallback: The fallback DB slows request threads.
